- Headers on response (set ONCE, after key + brand + focus loads succeed):
  - `Content-Type: application/x-ndjson`
  - `Cache-Control: no-cache`
  - `X-Accel-Buffering: no`
- Body events (each on its own line, JSON-encoded, terminated by `\n`):
  - `{"type":"chunk","text":"<delta>"}` - one or more
  - `{"type":"complete","postId":"<firestoreId>","slides":[...],"caption":"..."}` - exactly one, last
