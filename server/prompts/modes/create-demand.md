# Mode: Create Demand

## Goal
Reichweite, Engagement, Follower-Wachstum. Kein Produkt-Pitch. Kein Link, kein Journal, keine Methode.

## CTA Rules
- Kein Produkt, kein Link, kein "Link in Bio"
- Engagement-CTAs only: Speichern, Teilen, Folgen, Kommentieren
- Formulierung: spezifisch statt generisch. "Speicher Dir das für den nächsten schweren Abend" statt "Speichern"

## Constraints
- Hooks dürfen schärfer und provokanter sein als die Brand Voice
- Kein Capture-Link. Wer emotional getroffen wird, besucht das Profil organisch.
- Null Produkterwähnung. Nicht einmal indirekt ("ich schreibe abends auf...").

## Method-Spezifische Regeln

Die exakten Slide-Nummern definiert das Method-Template. Hier stehen nur die Rollen und Regeln pro Methode.

### Story (Create-Demand)
Voller emotionaler Bogen. Die Auflösung ist eine innere Erkenntnis, kein externes Werkzeug.
- **Emotion-Block** (erste Slides): Hook, Szene, Gefühl
- **Wendepunkt**: SAVE-MAGNET - Innere Erkenntnis (kein Produkt)
- **Resolution**: Reframe + Share-Trigger (Du-Perspektive)
- **CTA** (letzte Slide): Speichern + Teilen

### Liste (Create-Demand)
Kein Kontext-Slide. Hook direkt in die Punkte. Hook Contract: Zahl im Hook = Anzahl Inhaltspunkte.
- **Hook**: Dramatisch. "X Wahrheiten, die niemand über [Thema] ausspricht"
- **X Punkte**: Exakt X Punkte, jeder KOMPLETT UNABHÄNGIG. Stärkster Punkt auf Slide 2 (= 2nd Hook).
- **Übergang**: SAVE-MAGNET - Zusammenfassender Satz der alles verbindet + SHARE-TRIGGER
- **CTA**: Speichern + Teilen
- **Slide-Rechnung**: Hook(1) + X Punkte + Übergang(1) + CTA(1) = X + 3 Slides. Zahl im Hook = X.

Beispiel: "4 Wahrheiten" = Hook + 4 Punkte + Übergang + CTA = 7 Slides.

### Vorher/Nachher (Create-Demand)
Transformation durch inneren Shift, nicht durch Produkt. Der Bruch ist eine Erkenntnis, keine Handlung.
- **Vorher** (erste Slides): Hook (Kontrast), Vorher-Zustand, Vorher-Konsequenz
- **Bruch**: SWIPE-MAGNET - Ehrliche Erkenntnis (kein Produkt, keine Handlung)
- **Nachher**: Neuer Zustand + SAVE-MAGNET (universelle Lektion)
- **CTA** (letzte Slide): Speichern + Teilen

## Caption
Die Caption ergänzt das Carousel - sie wiederholt es NICHT. Die Leserin hat die Slides bereits gesehen. Eine Caption die den gleichen Inhalt nochmal zusammenfasst, fühlt sich redundant an und wird überscrollt.

Stattdessen:
- **Neuer Blickwinkel**: Erzähle den Moment dahinter, den Kontext, oder was Du vorher/nachher gedacht hast. Etwas das die Slides nicht zeigen.
- **Persönlicher Layer**: Warum Du das geteilt hast. Was es Dir bedeutet. Eine Erkenntnis die beim Schreiben kam.
- **Einladung zum Dialog**: Die Caption öffnet ein Gespräch. Sie stellt eine echte Frage, die echte Antworten einlädt - keine rhetorische Floskel.
- Erster Satz ist der Hook - er muss im Feed-Preview (erste 125 Zeichen vor "mehr") neugierig machen, ohne den Slide-Inhalt zu wiederholen.
- Max 150 Wörter
- Ende mit einer Frage, die Kommentare provoziert
- 5-8 Hashtags, deutsch. Pflicht-Hashtags aus Product-Context.
